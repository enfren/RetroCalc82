# RetroCalc-82

A retro 1982-style calculator built with vanilla HTML, CSS, & JS.

## Features

- Green phosphor LCD display
- Chunky 3D buttons with press animation
- Keyboard support (0-9, +, -, *, /, Enter, Esc)
- No dependencies — single HTML file
